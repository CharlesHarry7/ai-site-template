## 上线清单（Vercel + Neon）

用户要给：Stripe 测试密钥 + 3 个积分包和 2 个订阅的 Price ID；AI 接口密钥（AI Gateway 或 OpenAI）；Google OAuth 客户端；买域名（要用户确认）。密钥由用户填 `.env` / 交给命令行 `vercel env add`，不在浏览器表单里代填。

1. `vercel link` → Vercel 里开 Neon（Storage → Neon）→ `vercel env pull`。
2. `pnpm db:migrate`（对生产库）。
3. Stripe：建产品/价格 → 填 Price ID → Webhook 指向 `https://域名/api/stripe/webhook`，事件见 README。
4. `vercel --prod`，绑域名，Google OAuth 回调 `https://域名/api/auth/callback/google`。
5. 自测：注册 → 欢迎积分 → 生成 → 测试卡买积分包 → 余额增加；提交 GSC 站点地图。
